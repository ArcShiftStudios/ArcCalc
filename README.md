# ArcCalc ⬡

### A modern calculator by ArcShift Studios

ArcCalc is a modern calculator designed to combine practical functionality with a clean, intuitive interface. Built with the assistance of **Google AI Studio**, the project focuses on usability, thoughtful design, and a smooth calculation experience.

## ✨ Features

- 🧮 Basic arithmetic and scientific calculations
- 📐 Trigonometric functions
- 🕘 Calculation history
- 🎨 Customizable themes
- 🌙 A clean, modern dark interface
- 🖥️ Support for the platforms provided by the project

*Features and platform availability depend on the current release.*

## 🤖 Development & Testing

ArcCalc was developed with the assistance of **Google AI Studio**, which helped generate and implement the application.

However, generating code is only one part of development. The application has been **thoroughly tested by the developer**, with a focus on functionality, usability, and identifying potential issues.

AI-assisted development made the building process faster, while hands-on testing helped verify the application in practice.
